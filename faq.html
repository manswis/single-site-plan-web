Frequently Asked Questions

Everything you need to know about single plot layout plans, B-to-A Khata conversion standards, and PDF exports.

❓ Is this single plot layout plan legally compliant with BBMP standards? +
Yes! All generated plans strictly adhere to Bruhat Bengaluru Mahanagara Palike (BBMP) B-to-A Khata guidelines, KTCP Act Sec 17, and BDA RMP-2015 Master Plan setback bye-laws.
❓ What is the difference between B-Khata and A-Khata conversion? +
B-Khata is a temporary property tax register entry for unauthorized layouts. A-Khata is the official ownership khata certificate issued by BBMP for DC-converted properties with valid single plot layout plans.
❓ Do I still need a licensed architect signature on the generated plan? +
The generated PDF includes official COA/BBMP registration signature and seal blocks ready for your licensed architect or engineer to review, sign, and seal before final municipal submission.
❓ How does the software handle irregular or odd-shaped plots? +
You can toggle 'Irregular / Odd Shaped Site' mode in Step 3 to input exact independent measurements for North, South, East, and West boundaries. The vector engine automatically calculates non-rectangular geometry.
❓ Is my personal and property data kept private and secure? +
100% Yes! All data processing, SVG rendering, and PDF file creation occur locally inside your web browser. Zero property records or personal data are ever uploaded to any external server.
